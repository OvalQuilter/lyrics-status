---PATCHING-CONTEXT---
- Always read exact anchor strings before patching (substring probe, not full file)
- One PS call per file max; chain all replacements on same $c variable, write once
- Use [char]96 for backtick literals to avoid PS string parse errors
- CRLF is 
 — always use it in replacement strings
- Use [IO.File]::ReadAllText/WriteAllText with UTF8Encoding(False) — no BOM
- Verify with .Contains() checks in same call as write, never a separate read
- Never use str_replace — use .Replace() on in-memory string only
- Probe ambiguous anchors with .IndexOf()+.Substring() before committing
- dist/ only — no src/
