I'm getting HTTP 429 (rate limited) from Discord. ▼
Discord enforces a ~5 update per 20s limit on custom status. Raise Min interval to 10 000 ms or higher under Rate Limiting, or enable Gateway mode which bypasses REST rate limits entirely by using Discord's WebSocket (op 3).

No synced lyrics found for a song. ▼
Not every song has timed lyrics in every source. The app tries each enabled source in order â€” if all fail, no status is sent for that song. LrcLib has the broadest free coverage and requires no token. Try enabling all sources and restarting.
Musixmatch worked briefly then stopped (ok=false / captcha). ▼
Musixmatch's unofficial desktop endpoint actively rate-limits and flags tokens via bot-detection â€” this is a known issue across many projects, not a paid-plan requirement. Source order or toggle changes aren't taking effect. ▼
Source order and enabled/disabled toggles are loaded once at startup. After saving changes in the Sources section, restart the app (Ctrl+C then npm start) for them to take effect.
How do I get my Discord token? ▼
Open Discord in your browser, open DevTools (F12), go to the Network tab, send any message or perform any action, find a request to discord.com/api, and look for the Authorization request header. That value is your user token. Keep it private â€” it grants full access to your account.
